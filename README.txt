QUIZNOVA - ONLINE QUIZ APPLICATION
=================================
FILES
- index.html: page structure and interface
- style.css: responsive visual design, focus states and dark theme
- script.js: 11 category question banks and quiz logic

HOW TO RUN
1. Extract the ZIP to a folder.
2. Keep index.html, style.css and script.js together.
3. Double-click index.html to open it in Chrome or Edge.
4. Internet is only needed for optional Google Fonts; the quiz itself works locally.

FEATURES
- 11 quiz categories with 10 questions each (110 questions total)
- Easy, mixed and challenge difficulty filters
- Choose 5, 10 or all available questions
- Optional 20-second timer per question; selecting an answer does not reset the clock
- Randomised question order
- Previous, next and skip controls
- Pause/resume preserves the remaining question time
- Bookmarks and keyboard shortcuts (1-4, arrow keys, Escape)
- Sound toggle and dark/light theme
- Score calculation, explanations and answer review
- Practice incorrect answers
- Download result as a text file
- Local score history, best/average dashboard and reset controls
- Separate leaderboard for each quiz category with fictional demo names
- Fastest perfect-run record and best score per category
- Your scores join the leaderboard after each completed round on this device
- Responsive layout improvements for desktop, tablet and mobile
- Improved keyboard focus, category selection states and text wrapping

NOTE
Scores and theme choice are stored in this browser using LocalStorage. This is a front-end mini project and does not use a server or online user accounts.

LEADERBOARD NOTE
The initial leaderboard uses clearly fictional sample names and sample results for demonstration. When a quiz is completed, the result is saved to the same browser and can appear on that category leaderboard. This is a local demo, not a shared online leaderboard; syncing across devices/users requires a backend database and user identity system.

QUIZ CATEGORIES
Computer Science, Programming, General Knowledge, Mathematics, Science & Nature, English & Vocabulary, History & Geography, Cybersecurity, Aptitude & Reasoning, Sports & Games, and Web Development.
