ONLINE QUIZ APPLICATION — QUIZNOVA DESIGN
==========================================

Project title:
Online Quiz Application: A Web-Based Multiple-Choice Examination System

Files:
- index.html: page structure and quiz interface
- style.css: visual design, responsive layouts, gradients, cards, and animations
- script.js: question selection, navigation, scoring, review, and local score history
- README.txt: these instructions

HOW TO RUN ON WINDOWS
---------------------
1. Download and extract online_quiz_application.zip.
2. Open the extracted online_quiz_application folder.
3. Double-click index.html to open the project in Edge, Chrome, or Firefox.
4. Pick a category card and click "Let's play".
5. Answer the questions and finish the quiz to see your result.
6. Click "Review answers" to see correct answers and explanations.

OPTIONAL: RUN WITH VS CODE
--------------------------
1. Open Visual Studio Code.
2. Select File > Open Folder and choose this project folder.
3. Optional: install the Live Server extension.
4. Right-click index.html and select "Open with Live Server".

FEATURES
--------
- Three categories: Computer Science, Programming, and General Knowledge.
- Five MCQ questions in each category.
- Previous/Next navigation and progress bar.
- Responsive layout for phones and desktops.
- Illustrated quiz card, category cards, decorative shapes, hover effects, and gentle animation.
- Score, percentage, correct/incorrect counts, and answer explanations.
- Saves up to 20 recent scores in this browser using LocalStorage.

TECHNICAL NOTE
--------------
This is a front-end demonstration project. It has no server, user login, or shared database.
Saved scores are kept only in the current browser. Ask your project guide whether a database
is required before final submission.

SUGGESTED VIVA EXPLANATION
--------------------------
"My project is an Online Quiz Application called QuizNova. It is developed using HTML,
CSS, and JavaScript. HTML creates the website structure, CSS creates the responsive
interface and visual design, and JavaScript manages questions, answer selection,
navigation, and score calculation. The result screen displays the score and percentage,
and the answer review explains the correct answers. LocalStorage can save recent scores
in the same browser without a database."
